# AI Political Poster Maker (বাংলাদেশি রাজনৈতিক পোস্টার মেকার)

একটি পূর্ণাঙ্গ এআই চালিত ওয়েব প্ল্যাটফর্ম, যার মাধ্যমে স্থানীয় রাজনৈতিক কর্মী, প্রচার সম্পাদক ও সংগঠনসমূহ অতি দ্রুত ও নির্ভুলভাবে মুদ্রণ-উপযোগী (১২০০×১৬০০+ পিক্সেল) রাজনৈতিক পোস্টার (বিজয় দিবস, শোক ও স্মরণ, নির্বাচনী প্রচার, শুভেচ্ছা, ঈদ ও উৎসব) তৈরি ও ডাউনলোড করতে পারেন।

---

## 📌 Manual Actions Required (ম্যানুয়াল করণীয়)

> [!IMPORTANT]
> আপনি নির্দেশনায় জানিয়েছিলেন যে কোনো কনফিগারেশন বা ব্রাউজার কাজের প্রয়োজন হলে আলাদাভাবে উল্লেখ করতে। নিচে প্রয়োজনীয় ম্যানুয়াল পদক্ষেপগুলো দেওয়া হলো:

### ১. Google Gemini API Key সেটআপ (ঐচ্ছিক কিন্তু জেমিনি লাইভ ফিচারের জন্য আবশ্যক):
- আপনার ব্রাউজারে [Google AI Studio](https://aistudio.google.com/app/apikey) এ যান।
- একটি বিনামূল্যে **Gemini API Key** তৈরি বা কপি করুন।
- প্রজেক্টের `backend/.env` ফাইলে কি-টি পেস্ট করুন:
  ```env
  GEMINI_API_KEY=AIzaSy...আপনার_কি_এখানে
  ```
  *(নোট: এপিআই কি না দিলেও সিস্টেম ক্র্যাশ করবে না; স্বয়ংক্রিয়ভাবে একটি বুদ্ধিমান অফলাইন ফলব্যাক এআই ইঞ্জিন সক্রিয় থাকবে।)*

### ২. MongoDB সংযোগ (ঐচ্ছিক):
- সিস্টেমে সরাসরি জিরো-কনফিগ **Embedded MongoMemoryServer** ইন্টিগ্রেট করা রয়েছে, তাই আপনার কম্পিউটারে আলাদাভাবে মঙ্গোডিবি ইন্সটল না থাকলেও এটি সাথে সাথেই চলবে।
- আপনি যদি নিজস্ব MongoDB Atlas বা লোকাল সার্ভিস ব্যবহার করতে চান, তবে `backend/.env` ফাইলে আপনার ইউআরআই প্রদান করতে পারেন:
  ```env
  MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/political_posters
  ```

## 🛠️ প্রযুক্তিগত কাঠামো (Tech Stack)

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS, Lucide Icons, html2canvas, jsPDF
- **Backend**: Express.js, TypeScript, Mongoose, Multer, Sharp (High-Res 1200x1600 Graphics Composite), JWT, BcryptJS
- **Database**: MongoDB (Mongoose Schema + MongoMemoryServer zero-config fallback)
- **AI Integration**: Google Gemini API (`@google/generative-ai`)
- **Bangla Typography**: Google Fonts (`Tiro Bangla`, `Hind Siliguri`, `Anek Bangla`)

## 🌟 মূল ফিচারসমূহ (Core Features - MVP)

1. **টেমপ্লেট গ্যালারি (Template Library)**:
   - ১৬ই ডিসেম্বর মহান বিজয় দিবস
   - গভীর শোক ও স্মরণ শ্রদ্ধাঞ্জলি
   - আসন্ন নির্বাচনী গণসংযোগ ও প্রচার
   - আন্তরিক শুভেচ্ছা ও অভিনন্দন
   - পবিত্র ঈদ মোবারক ও উৎসব

2. **পোস্টার তৈরির ফর্ম (Interactive Form)**:
   - নাম, পদবি, রাজনৈতিক দল/সংগঠন, এলাকা (ইউনিয়ন/থানা/জেলা)
   - মূল ব্যানার শিরোনাম ও উপ-শিরোনাম
   - ৩টি ফটো আপলোড স্লট (প্রার্থীর ছবি + শীর্ষ ২ জন নেতার কাটআউট ফ্রেম)
   - জেমিনি এআই চালিত আকর্ষণীয় রাজনৈতিক ছন্দময় স্লোগান জেনারেটর
   - ঐতিহ্যবাহী "- প্রচারে -" (Promoted by) ক্রেডিট লাইন

3. **লাইভ প্রিভিউ ও রি-জেনারেট (Live Preview & Studio)**:
   - তাৎক্ষণিক লাইভ ক্যানভাস প্রিভিউ
   - বাংলা ফন্ট পরিবর্তন (তিরো বাংলা, হিন্দ শিলিগুড়ি, অনেক বাংলা)
   - ৫ বার পর্যন্ত সার্ভার ও এআই রি-জেনারেট করার সুবিধা

4. **প্রিন্ট-রেডি এক্সপোর্ট (Download & Export)**:
   - ১২০০×১৬০০ হাই-রেজুলেশন প্রিন্ট-উপযোগী **PNG**
   - সরাসরি প্রিন্টযোগ্য **PDF** ফাইল ডাউনলোড

5. **পোস্টার হিস্টোরি (User History)**:
   - ব্যবহারকারীর অ্যাকাউন্টে পূর্বের তৈরি সকল পোস্টার সংরক্ষিত থাকে
   - যেকোনো সময় পুনরায় ডাউনলোড বা মুছে ফেলার সুবিধা

6. **অ্যাডমিন প্যানেল (Admin & Moderation Queue)**:
   - পোস্টার মডারেশন কিউ (অনুমোদিত বা ফ্ল্যাগড/নিষিদ্ধ চিহ্নিত করা)
   - টেমপ্লেট সক্রিয়/নিষ্ক্রিয়করণ ব্যবস্থাপনা
   - এআই খরচ ও রিকোয়েস্ট লগ মনিটরিং

## 🚀 লোকাল মেশিনে যেভাবে চালাবেন (How to Run Locally)

### ১. ডিপেন্ডেন্সি ইন্সটল (ইতিমধ্যে সম্পন্ন):
```bash
npm install --prefix backend
npm install --prefix frontend
```

### ২. ডেটাবেজ সিড (টেমপ্লেট ও ডেমো অ্যাকাউন্ট প্রস্তুত করা):
```bash
npm run seed
```

### ৩. ব্যাকএন্ড ও ফ্রন্টএন্ড চালু করা:
- **ব্যাকএন্ড চালু করুন (Port 5000)**:
  ```bash
  npm run dev:backend
  ```
- **ফ্রন্টএন্ড চালু করুন (Port 3000)**:
  ```bash
  npm run dev:frontend
  ```

ব্রাউজারে ভিজিট করুন: **`http://localhost:3000`**

## 📡 API Endpoints

- `POST /api/auth/register` — নতুন অ্যাকাউন্ট নিবন্ধন
- `POST /api/auth/login` — লগইন ও JWT টোকেন প্রদান
- `GET /api/templates` — টেমপ্লেট তালিকা (ক্যাটাগরি ফিল্টার সহ)
- `GET /api/templates/:id` — নির্দিষ্ট টেমপ্লেটের বিবরণ
- `POST /api/posters` — পোস্টার তৈরি ও এআই প্রসেসিং
- `GET /api/posters/:id` — পোস্টার রেজাল্ট ও প্রিভিউ
- `GET /api/posters/user/:userId` — ব্যবহারকারীর পোস্টার হিস্টোরি
- `POST /api/posters/:id/regenerate` — পোস্টার রি-জেনারেট
- `DELETE /api/posters/:id` — পোস্টার মুছে ফেলা
- `POST /api/upload` — ফটো আপলোড
- `GET /api/admin/posters` — মডারেশন কিউ
- `PATCH /api/admin/posters/:id/moderate` — পোস্টার অনুমোদন বা ফ্ল্যাগ
- `PATCH /api/admin/templates/:id` — টেমপ্লেট একটিভ/ইনঅ্যাক্টিভ টগল
